# Landing Page

A responsive landing page built with **HTML and CSS** as part of my learning journey.

The project focuses on building a structured, visually appealing landing page from scratch while practising modern CSS layout techniques, including **Flexbox and CSS Grid**.

## Features

* Navigation header
* Navigation links
* Hero section with large background/image content
* Call-to-action section
* Seasonal image showcase
* Inspirational quotes section
* Sign-up buttons
* Responsive layout
* Custom styling and colour scheme
* Google Fonts integration
* Custom image assets

## Technologies

* **HTML5** — Page structure and semantic content
* **CSS3** — Styling and layout
* **CSS Flexbox** — Flexible page and component layouts
* **CSS Grid** — Structured multi-column layouts
* **Google Fonts** — Roboto typography

## Page Sections

### Header

The header contains a logo/title and navigation links to external websites.

### Hero Section

The main hero section introduces the website with a large heading, supporting text, sign-up button and featured image.

### Seasonal Images

A dedicated section showcases images representing the four seasons:

* Spring
* Summer
* Autumn
* Winter

Each image is accompanied by a short description.

### Inspirational Quotes

The page includes an inspirational quotes section with quotes and their attributed authors.

### Call to Action

A highlighted call-to-action section encourages visitors to sign up.

### Footer

The footer contains copyright information for the project.

## Layout

The page uses a combination of **Flexbox and CSS Grid** to organise its different sections.

The layout includes multiple content areas while maintaining consistent spacing, sizing and alignment throughout the page.

### 2. Navigate into the project

```bash

```

### 3. Open the application

Open `index.html` in your browser.

No additional dependencies or installation steps are required.
